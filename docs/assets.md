Nintendo의 로고, 캐릭터, 화면 캡처, 모델, 텍스처 또는 음원은 게임 번들에 포함하지 않는다. 참고 링크는 `references.md`에 남기며, 인용 영상의 저작권은 해당 권리자에게 있다. 외부 CDN에서 실행 중에 자산을 받지 않으므로 자산 요청 실패로 주사위가 비는 경로를 줄였다.

## 라이브러리

직접 사용한 Three.js / React / Vite / TypeScript 등 의존성의 라이선스 원문은 각 npm 패키지의 LICENSE 파일과 잠금 파일의 패키지 정보를 따른다. Three.js의 [MIT 라이선스](https://github.com/mrdoob/three.js/blob/dev/LICENSE)를 확인할 수 있다. 이 문서는 해당 라이브러리의 권리를 프로젝트가 소유한다고 주장하지 않는다.

## 그래픽·오디오 구현 메모

- 색 관리는 SRGB 출력과 ACES filmic tone mapping을 사용한다. 512px의 자체 텍스처, 최대 DPR 1.75, 1024px 그림자를 기본으로 하고 느린 프레임이 지속되면 경과 시간에 비례해 DPR 및 그림자 해상도를 낮춘다. 최저 단계에서는 동적 그림자 대신 가벼운 접촉 그림자를 유지한다.
- 소프트웨어 래스터라이저(SwiftShader/llvmpipe 등) 또는 4개 이하 하드웨어 스레드에서는 처음부터 가벼운 모드를 선택한다. 환경 반사 맵의 초기 베이킹과 동적 그림자를 생략하고 DPR을 1로 제한하여 UI 초기화가 오랫동안 막히지 않게 한다. 일반 GPU 모드와 게임 규칙·최종 눈은 같다.
- 정지된 장면은 requestAnimationFrame을 계속 돌리지 않는다. ResizeObserver, 사용자 입력 또는 짧은 진행 중 연출이 있을 때만 렌더링한다. 비활성 탭에서는 렌더링과 오디오를 멈춘다.
- WebGL 컨텍스트 손실 시 한국어 안내와 HTML 주사위 조작을 유지하고, 복구 시 최신 확정 자세로 돌아간다. dispose 시 geometry, material, texture, shadow map, 환경 맵과 AudioContext를 정리한다.
- 효과음과 음악은 독립 gain을 거쳐 공통 compressor와 bounded waveshaper를 통과한다. 동시 발음 수와 짧은 중복 이벤트 간격도 제한한다. 첫 사용자 동작에서만 AudioContext를 만들고 재개한다.
- 실제 청취 여부는 별도로 기록한다. 코드 생성·오디오 자동재생 정책 처리만으로 음질을 실제 청취 검증했다고 표현하지 않는다.

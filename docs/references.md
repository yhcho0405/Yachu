# 원작 참고와 적용 기록

확인일: 2026-09-06. 이 문서는 실제로 확인한 자료와 구현에서 새로 정한 표현을 구분한다.

## 실제 확인한 자료

- [Nintendo 공식 소개 페이지](https://www.nintendo.com/ph/switch/as7t/index.html): Yacht Dice가 포함된 테이블 게임 모음이며, 혼자 및 다른 사람과 즐기는 플레이 구성을 확인했다.
- [CBGames의 Nintendo Switch Yacht Dice 실제 플레이 영상](https://www.youtube.com/watch?v=i-fJ5ENHSiw): 브라우저의 실제 영상 플레이어에서 광고를 건너뛴 뒤 **4:27, 4:40, 4:45**의 게임 프레임을 직접 보았다. 제목 이미지와 실제 플레이 프레임을 구분했다. 영상 전체를 시청한 것은 아니다. 소리는 음소거했으므로 원작 효과음·음악을 청취했다고 주장하지 않는다.
- 규칙의 수치는 사용자 지정 표를 구현의 기준으로 삼는다. [사용자가 지정한 분석 자료](https://smooth-pudding.hatenablog.com/entry/2024/08/11/181557)는 규칙 문서에서 별도로 대조한다. 위에서 확인한 짧은 영상 구간만으로 풀 하우스의 다섯 개 동일 눈 예외를 영상 검증했다고 주장하지 않는다.

## 연출을 새로 결정한 범위

- 정상 굴림은 1,100ms, 보관 이동은 280ms다. 이 값은 원작 영상에서 밀리초 단위로 실측한 값이 아니라 요구 범위에 맞춘 프로젝트 설정이다.
- 서버 결과를 먼저 받은 뒤 그 면을 향해 연속적인 quaternion 보간과 감쇠 회전을 수행한다. 멈춘 뒤 눈의 그림을 교체하지 않는다. 서로 떨어진 고정 레인과 둥근 상자 지지 높이를 이용한 제한된 물리 기반 연출이며, 범용 강체 시뮬레이터는 사용하지 않는다.
- 주사위 소리는 필터를 거친 잡음과 감쇠 진동으로 직접 합성한다. 차분한 네 코드 배경음도 직접 작성했다. 원작 소리나 멜로디를 추출하거나 복제하지 않았다.
- 1~4인 온라인 방, 게스트 인증, 재접속 유예 및 기권은 이 프로젝트의 온라인 확장이다. 원작 정책이라고 표기하지 않는다.

## 확인 범위의 한계

원작 전체 영상, 원작 사운드의 청취, 원작의 정확한 물리·카메라 수치까지 분석한 것은 아니다. 이 저장소의 브라우저 테스트 결과와 스크린샷·녹화는 테스트 기록에 별도로 남긴다. 자동화된 오디오 노드·설정 동작 확인과 실제 스피커 청취는 별개의 검증이다.

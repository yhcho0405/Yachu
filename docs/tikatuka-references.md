확인일: 2026-09-06. 로스트아크 원본 클라이언트가 보이는 영상과 게임 내부 규칙 화면을 우선한다. 팬게임 구현은 근거로 사용하지 않았다. 규칙의 최종 대조표는 `tikatuka-rules-research.md` 및 최종 규칙 문서와 함께 확인한다.

## 추가 원작 홀드 확인

[겜빡이존의 원작 플레이 영상, 05:15](https://www.youtube.com/watch?v=UsYzsoVJul0&t=244s)을 실제 Chrome YouTube 플레이어에서 직접 대조했다. 04:04.24에는 내 점수가 `[13,25,9]`이고 아래 라인은 `[6,3]`으로 한 칸이 비어 있으며 대기 홈에 일반 5가 있다. 04:05.43에는 홈의 5가 사라졌지만 아래 라인은 여전히 `[6,3]`이고, `홀드` 버튼이 회색 체크로 바뀌며 상대 `TURN`이 켜진다. 04:07에도 체크가 남고, 04:12에는 다음 경기의 대진 화면으로 넘어간다. 이는 실제 홀드가 현재 주사위를 배치하지 않고 버리며 보드를 유지하는 사례다. 확인한 프레임에서는 별도 상대 수락 팝업을 보지 못했다. 이것만으로 홀드 해제 가능 여부나 별도의 승부사 선언 계약을 확정하지 않았다.

## 실제 보드의 시각 구성

- 양쪽 보드는 화면 **왼쪽과 오른쪽**에 놓이고, 각 보드의 세 라인이 수평으로 길게 나란히 쌓인다. 화면의 같은 높이에 있는 두 라인이 대응한다. 각 라인은 개별 숫자 타일 세 개가 들어가는 넓은 목재 홈이며, 원작 화면에서는 독립된 작은 정사각형 세 칸으로 분할되어 있지 않다.
- 중간 좁은 영역에 두 라인의 점수가 서로 마주 보게 표시된다. 녹색·주황색 방향 표시는 현재 우세 쪽을 가리키고, 동점에는 가운데 짧은 선이 보인다. 전체 합계보다 세 쌍의 대결을 먼저 읽게 한다.
- 보드 바깥쪽의 깊고 긴 홈이 현재 주사위와 재굴림 후보를 담는다. 왼쪽은 녹색, 오른쪽은 붉은 갈색이다. 둘 사이의 보드 본체는 따뜻하고 어두운 나무이며, 바깥 테두리에는 더 두꺼운 목재와 금속 띠·리벳처럼 보이는 장식이 있다.
- 주사위는 둥근 아이보리 몸체에 각 플레이어의 녹색·붉은 눈을 사용한다. 1은 원작 캐릭터를 연상시키는 작은 새싹 표식이다. 실드는 눈 위를 덮는 큰 이펙트 대신 몸체 가장자리의 색 띠로 구별된다. 이 프로젝트에서는 원작 새싹·캐릭터·장식을 복사하지 않고 자체 숫자 눈과 별도의 실드 표식을 제작한다.
- 현재 행동이 가능한 라인은 밝은 테두리, 다른 라인은 어두운 테두리로 구분된다. 단순 색뿐 아니라 경계 대비가 입력 가능 영역을 설명한다. 같은 눈 조합에는 주사위 사이의 작고 얇은 아이콘을 사용한다.
- 특수 재굴림과 홀드는 왼쪽 대기 홈 아래에 위치한다. 상대의 재굴림 사용 여부도 오른쪽에 표시된다. TP와 베팅 정보는 위·아래 중앙에 있으나 웹 서비스에서는 재화 경제를 옮기지 않는다.

## 기존 야추 보존과 자체 제작 범위

기존 야추의 둥근 모서리, 서버 값에 맞는 quaternion 최종 자세, 접촉 그림자, 색 관리와 안정적인 카메라를 보존 기준으로 삼는다. 공통 음소거·볼륨·모션 감소 저장 키를 유지한다. 새 티카투카 장면은 게임별로 지연 로드하며, 전환 시 RAF·리스너·WebGL 및 오디오 자원을 정리한다.

티카투카의 모델·재질·눈·실드 표시·효과음은 독립 제작한다. 원작 스크린샷, 캐릭터, 텍스처, 모델과 음원은 실행 번들에 포함하지 않는다. 대응 라인의 안정적인 가독성을 유지하되, 사이트의 크림·그린·목재 계열과 어울리는 조명과 재질을 사용한다. 원작 영상에서 직접 보지 못한 타격 시간·곡선·사운드 질감을 원작 수치로 표기하지 않는다.

## 아직 확인해야 하는 사항

최초 선공 결정의 구체적 절차, 재굴림에서 기존 눈을 제외하는지, 홀드의 해제 가능 여부·모든 종료 조합, 선언 조건·상대 응답·판정 영향, 공격 선택 취소의 정확한 확정 시점, 만석 보드의 재활성화는 추가 원작 규칙 화면 또는 상태 전이 근거가 필요하다. 영상을 몇 장 본 것만으로 이 항목들을 원작과 동일하게 구현했다고 보고하지 않는다.

## 구현과 시각 검증 연결

독립 구현은 `src/client/games/tikatuka/scene.ts`, `materials.ts`, `motion.ts`, `audio.ts`에 있다. 원작의 좌우 세 줄 구조는 데스크톱에서 유지하고, 좁고 긴 화면에서는 내 보드가 아래·상대 보드가 위에 놓이도록 보드 전체를 회전한다. 논리적인 소유자 ID와 줄 번호는 회전해도 바꾸지 않는다. 카탈로그 WebP는 실제 자체 Three.js 장면을 캡처한 정적 이미지이며 원작 게임 화면이 아니다. 검증 방법과 수치는 `tikatuka-graphics-verification.md`에 기록한다.

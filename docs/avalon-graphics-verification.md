# 아발론 장면·효과음 검증

확인일: 2026-09-06. 새 Avalon 장면은 `AvalonPublicState`와 해당 브라우저의 선택 초안만 받는다. 실제 역할, 원정 카드 작성자, 개인 투표/카드 선택은 장면에 전달하지 않는다. 장면은 종료 역할 목록도 읽지 않는다. 상업용 보드·역할 카드 이미지를 가져오지 않고 목재·돌 텍스처, 문장, 카드, 촛대와 금속 토큰을 코드로 제작했다. `public/previews/avalon.webp`는 이 장면을 직접 캡처한 960×540 이미지다.

## 공개 정보와 연출

- 좌석 1은 원탁 뒤쪽에 고정되고 좌석 번호가 시계방향으로 증가한다. 대장이 바뀌어도 카메라나 좌석이 회전하지 않는다. 중립 색상의 말·왕관·원정대 토큰·동일한 제출 봉인·연결 끊김 표식은 공개 상태만 나타낸다.
- 이름과 자세한 상태는 투영된 HTML 앵커와 전체 좌석 목록이 담당한다. 같은 플레이어 ID가 캔버스 raycast와 HTML 선택 콜백으로 전달된다.
- 투표 공개 전에는 동일한 뒷면과 제출 여부만 표시한다. 전원 제출 뒤 공개된 개인 찬반은 동시에 좌석에 표시한다.
- 원정 결과 카드는 성공/실패 **집계 개수만**으로 새로 배치한다. 카드 객체에 플레이어 ID나 카드 ID를 저장하지 않는다. 공개 애니메이션은 중앙 내부에서만 뒤집고 펼치며, 특정 좌석에서 결과 카드로 이동하는 경로가 없다. 실패 효과는 중앙 카드와 해당 원정 표식에 한정된다.
- 호수의 여인은 공개된 토큰 소유자 이동만 나타낸다. 조사 진영은 색상이나 효과에 반영하지 않는다.
- 실제 사건 ID당 한 번만 효과를 시작한다. UI 선택, 권한 갱신, 대화 신호가 같은 사건을 재생하지 않는다. 새 서버 상태는 즉시 반영하며 애니메이션 완료를 기다려 행동을 허용하지 않는다. 모션 감소에서는 최신 상태를 한 번 렌더한다.

## 실제 10인 UI 최종 확인

최종 로컬 workerd `http://127.0.0.1:8788`에서 10개의 독립된 신규 게스트를 정상 UI로 참가시켜 한 원정을 진행했다. 대장이 보드의 HTML 이름 버튼으로 3명을 선택·확정한 뒤 10명이 찬성을 제출했다. 원정대원 각자의 화면에서 허용된 카드를 선택·제출해 **성공 2장, 실패 1장**이 익명 집계로 공개됐다. 난수·역할·서버 상태를 주입하지 않았다. 역할 패널은 모든 공유 이미지와 영상에서 닫혀 있다. 촬영 후 10명 모두 정상 UI로 퇴장했다. 이전 사용자 미리보기 8787이나 기존 사용자 세션은 변경하지 않았다.

| 뷰포트 | 실제 보드 영역 | 문서 가로 넘침 | 10개 HTML 이름 겹침 |
| --- | --- | --- | --- |
| 1366×900 | 920×450 | 없음 | 없음 |
| 360×900 | 334×440 | 없음 | 없음 |
| 900×900 | 850×470 | 없음 | 없음 |
| 1920×1080 | 1154×450 | 없음 | 없음 |

모바일 이름 11px·상태 10px·최소 44px 높이가 실제 계산 스타일에 적용됐음을 확인했다. 긴 이름은 말줄임과 펼칠 수 있는 상세 좌석 목록을 사용한다. 데스크톱에는 조작 패널이 보드 오른쪽에 있어 투표·카드 제출과 원탁을 함께 볼 수 있다. 고정 카메라는 넓은 보드에서 약 41°, 좁은 세로 영역에서 약 62°이며 게임 진행 중에는 회전하지 않는다. 네 가지 크기의 실제 UI 스크린샷을 직접 확인했고 페이지 JavaScript 오류는 0개였다. 이 모바일·태블릿 검사는 동일한 Mac의 브라우저 뷰포트 변경이며 실물 휴대폰의 GPU·터치 성능 검사가 아니다.

최종 근거는 `work/avalon-graphics/ui-capture.json`, `ui-1366.png`, `ui-360.png`, `ui-900.png`, `ui-1920.png`에 있다. `avalon-gameplay.mp4`는 **9.28초·1366×900·25fps의 무음 정상 UI 녹화**다. 녹화의 25fps를 게임 렌더링 성능으로 해석하지 않는다. 대략 0.5초에 원정대 구성, 3.8초에 9/10 투표 제출, 5.8초에 원정 카드 제출 대기, 6.6초에 익명 결과·해당 원정 표식의 균열이 보인다. 이 네 프레임과 7.5초의 결과 화면을 직접 확인했다. 실패 카드가 어느 참가자의 것인지 표시하거나 특정 좌석으로 실패 연출을 보내지 않는다.

## 격리 장면의 실제 GPU 검사

macOS arm64의 Playwright Chromium 153.0.8010.12를 일반 headful 방식으로 실행했다. 강제 SwiftShader를 사용하지 않았다. 실제 renderer는 `ANGLE (Apple, ANGLE Metal Renderer: Apple M5 Pro, Unspecified Version)`이다. 별도 진단 페이지에서 읽기 전용 공개 상태 예제를 실제 scene 모듈에 전달했다. 이 예제를 정상 네트워크 경기나 실제 휴대폰 성능으로 해석하지 않는다.

- 1000×670, DPR 1에서 10석을 실제 포인터 raycast로 클릭하여 모든 플레이어 ID가 정확히 반환됨을 확인했다.
- 336×440과 744×500에서 10개 HTML 이름 앵커의 사각형이 겹치지 않음을 계산하고 스크린샷으로 직접 확인했다. 이 이름은 짧은 진단용 이름이며 실제 앱의 긴 닉네임 처리는 별도 UI 확인 대상이다.
- 원정 결과 공개 250ms 뒤 같은 사건을 `animate:false`로 다시 전달했을 때 연출이 유지되고 원정 효과음은 한 번만 발생했다. 공개 종료 뒤에는 확정 집계 카드가 그대로 남는다.
- 정지 상태 1초의 scene RAF 호출은 0회였다. 850ms 공개 연출의 연속 프레임 간격 101개는 중앙값 8.30ms, 95백분위 9.00ms였다. 최장 구간은 32.20ms였고 16.7ms를 넘은 구간은 1개였다. 이는 단일 장면의 짧은 측정이며, 10개 브라우저 동시 실행이나 저사양 휴대폰의 성능 보증은 아니다.
- 모션 감소 상태의 새 사건은 1회 렌더 후 멈췄다. dispose 뒤 남은 장면 canvas는 0개였고 JavaScript 오류는 없었다.
- `WEBGL_lose_context` 확장을 이용한 명시적 손실/복구 검사에서 복구 안내가 나타났다가 해제되고 실제 WebGL 컨텍스트가 회복됐다. 이 검사는 운영체제에서 자연 발생한 GPU 오류가 아니다.

로컬 근거: `work/avalon-graphics/scene-check.json`, `lifecycle-check.json`, `ten-desktop.png`, `ten-336.png`, `ten-744.png`, `anonymous-quest.png`. 진단 도구는 `work/avalon-qa.html`, `work/avalon-scene-check.mjs`에 있으며 production 디버그 API나 전역 변수를 추가하지 않았다.

## 수학·효과음·자원 정리

`tests/avalon-visual-layout.test.ts`의 3개 테스트는 5~10석의 고정 방향 및 비중첩 영역, 1~10장 카드 배치, 제출자·제출 순서를 바꿔도 익명 카드 출력이 같음을 검증한다. 시각 파일 ESLint와 전체 TypeScript 검사가 통과했다.

Avalon 효과음은 별도의 절차적 BGM을 만들지 않는다. 공통 음악 엔진과 독립된 효과음만 제공한다. 선택·대장·제출·투표·부결·원정 성공/실패·호수의 여인·종료·대화의 10종을 구분하고 이벤트별 제한과 최대 32개 발음을 적용한다. 마지막에 compressor와 최대 0.7의 bounded waveshaper를 통과한다.

실제 AudioContext를 관찰한 자동 검사에서 최초 사용자 제스처 전 컨텍스트는 0개였다. 10종 효과음을 의도적으로 겹친 표본의 최대 peak는 0.23136, 최대 RMS는 0.06870였고 음소거 뒤 peak는 0이었다. dispose 뒤 컨텍스트는 `closed`였다. **실제 소리 청취는 하지 않았으므로 음색·믹스에 대한 청취 품질 평가를 했다고 주장하지 않는다.**

ResizeObserver, 포인터·visibility·컨텍스트 이벤트, RAF, geometry/material/texture, shadow, 환경 맵 및 WebGL 컨텍스트를 정리한다. 소프트웨어 renderer와 낮은 하드웨어 병렬도에서는 DPR·동적 그림자·환경 맵 비용을 줄이며, 지속적으로 비싼 렌더가 관측되어도 DPR과 그림자를 낮춘다. 정지 장면의 품질 확인용 폴링 루프는 없다.

별도 네이티브 창/탭 전환 시도에서는 `document.hidden`이 실제로 변경되지 않았다. 따라서 코드의 숨김 시 정지·복귀 경로는 검토했지만 이번 Avalon 검사에서 실제 운영체제의 배경 전환과 오디오 중단을 검증했다고 주장하지 않는다.
